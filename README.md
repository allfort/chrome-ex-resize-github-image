## 概要
GitHubのPull RequestやIssueで添付した画像のサイズを、簡単に変更できるChrome拡張機能です。
面倒な画像サイズの調整をワンクリックで解決します。

## 主な機能
- Markdown記法の画像を自動で<img>タグに変換
- スライダー操作で100px～800pxまで、50px単位でサイズを調整
- リアルタイムでプレビューに反映

## 使い方
1. GitHubのPull RequestまたはIssueページに画像を添付
2. ブラウザのツールバーに表示される拡張機能アイコンをクリック
3. ポップアップ内のスライダーを動かして、希望の画像サイズを選択
